Privacy Policy for

Last Updated: March 2024

Overview

π TEX is a browser extension that helps users extract and copy LaTeX equations from AI chat interfaces. We prioritize user privacy and operate with minimal data access.

Data Collection & Usage

  • What We Access:
    • Page content on supported platforms (ChatGPT, Deepseek, Abacus AI) - only to extract LaTeX equations
    • Clipboard access - only when you explicitly copy an equation
    • Local storage - to save your preferences
  • What We Don't Do:
    • No collection of personal information
    • No tracking or analytics
    • No data sharing with third parties
    • No external data transmission

Required Permissions

  • clipboardWrite: Only for copying equations when requested
  • storage: For saving preferences locally
  • Host Access: Limited to chatgpt.com, chat.deepseek.com, and apps.abacus.ai

Your Rights

  • Clear local data through browser settings
  • Disable/remove extension anytime
  • Control permissions via browser settings
